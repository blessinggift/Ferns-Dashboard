# Ferns-Dashboard
This project presents a sales analysis dashboard built using Microsoft Excel to uncover key business insights for Ferns and Petals (FNP), a gifting platform. The dashboard explores sales performance, customer behavior, product trends, and delivery efficiency across multiple dimensions.
Key Features:

Revenue and order trend analysis

Customer spending behavior

Product and category performance

City-wise order distribution

Occasion-based sales insights

Analysis of order quantity vs. delivery time

Tools & Techniques:
Power Pivot | Power Query | DAX | Pivot Tables | Charts | Slicers | Data Modeling

The interactive dashboard enables FNP to make data-driven decisions for optimizing sales strategy, marketing focus, and logistics operations.
